# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Add an explicit directory picker with `Ctrl-O` in the workspace Directory field.
- Add a clickable **Browse (Ctrl-O)** button beside the workspace Directory field.
- Support hidden directories, parent navigation, and manual selection without search dependencies.

### Changed

- Restore the original directory completion with history, local children, and bounded project discovery.
- Remove automatic full-home discovery and its background search jobs.
